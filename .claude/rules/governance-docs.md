# ガバナンス文書（AGENTS.md / ルート CLAUDE.md）の構造を改変するときのルール

これらの文書は skills・rules・他 docs から参照されている。**他文書を指すときは正準形 `` `<対象>`「<見出し>」 ``（対象は `<path>.md` か `/skill-name`）で書く。** この形だけが `governance:check` の G11 で照合され、見出しの改名・消滅は参照元を名指しして CI が落とす。**序数（「ステップ 3」「Step 8」）で他文書を指してはならない**——番号は構造を凍らせ、ずれても誰も気づかない。

- **G11 が見るのは正準形だけである。** 散文形（「ルート `CLAUDE.md` のフック節」）・節を移動したときの意味の変化・番号参照は検知されない。ゆえに**移動・圧縮・分割の完全性は依然として機構の外**にあり、`/plan-review`「Step 2b」相当の**独立再導出**（旧内容を SSOT に、全命題の着地を作者と別枠組みで確認）で裏取りする。手順の SSOT は `/plan-review`「Step 2b」。
- **既に消滅した節の名前を正準形で書かない。** 正準形は「今ある場所への指し」であって過去の名前の記録ではない（`PERFORMANCE.md` が消滅済みの節を指したまま腐っていた実例が G11 導入時に見つかっている）。歴史を書くならバッククォートを外して散文にする。
- **これらの編集に PostToolUse hook 検査は走らない**（`selectChecks` がガバナンス文書に検査を割り当てず空集合を返す。`CLAUDE.md`「フック」）。G11 を含む決定的な検査は PR CI の governance-check job が事後に走る（#587）。
