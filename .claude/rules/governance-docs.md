# ガバナンス文書（AGENTS.md / ルート CLAUDE.md）の構造を改変するときのルール

これらの文書は、skills・rules・他 docs から**セクション名・Step 番号・引用された見出し語句**で参照されている。構造の改変（節の改名・移動・番号ずらし・圧縮・分割）は、それらの参照を**静かに腐らせる**——参照側は編集されず、壊れても loud に落ちない。

- **改変前に、参照側を「名前」と「序数」の両方で数え上げる。** 当の語だけの grep は概念ラベル参照に届かない。**半角「Step」と全角「ステップ」の両方**、および引用された見出し語句（例:「全称表現は前提条件とセットで書く」「事前調査（レビュー未然防止）」）で grep する（#482 の実例: `Step [0-9]` だけの grep が全角「ステップ」参照を漏らし、名前で参照している箇所を腐らせかけた）。**列挙は真実源のツール自身に問う**——グロブの意味論はツールごとに違う（#471）。**直すときは番号でなく名前で参照し直す。**
- **これらの編集に PostToolUse hook 検査は走らない**（`selectChecks` がガバナンス文書には検査を割り当てず空集合を返す。ルート `CLAUDE.md` のフック節）。ゆえに移動・圧縮・分割の**完全性は機構では担保されない**——`/plan-review` Step 2b 相当の**独立再導出**（旧内容を真実源に、全命題の着地を作者と別枠組みで確認）で裏取りする。列挙・完全性の詳細と手順の SSOT は `/plan-review` Step 2b。
