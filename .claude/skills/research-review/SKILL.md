`workspace/research.md` を読み、内容に基づいてサブエージェントを並列起動して検証する。

## Step 1 -- research.md の読み込み

`workspace/research.md` を読み、以下を把握する:

- issue の要約（何を解決するか）
- 関連コードとして挙げられているファイル・モジュール・関数
- 技術的制約として挙げられている事項
- 未解決の疑問（あれば）

## Step 2 -- 並列サブエージェントで検証

research.md に記載された関連コードのレイヤー（Rust / TypeScript / 設定 など）ごとにサブエージェントを分割して並列起動する。

各サブエージェントへの指示に含めるもの:

1. **担当レイヤーと対象ファイル**: research.md に記載のファイルを起点にする
2. **検証観点**:
   - 記載されたファイル・関数が実際に存在し、説明が正確か
   - そのコードパスと**対称ペア**（`show`/`hide`、`enter`/`exit` 等）がないか
   - 同じ処理パターンが他ファイルに存在し、影響範囲として漏れていないか
   - 記載されていない呼び出し元・呼び出し先で影響を受けそうな箇所がないか
3. **出力形式**: 「確認済み」「漏れの疑い」「要確認」の3分類で列挙

サブエージェントは `Explore` タイプを使用する。

## Step 3 -- 結果の統合と報告

各サブエージェントの結果を統合し、以下の形式で報告する:

```
## research-review 結果

### 確認済み（research.md の記述が正確）
- ...

### 漏れの疑い（影響範囲に含めるべき可能性）
- ...

### 要確認（調査が不十分または記述が不明確）
- ...

### 総評
research.md の completeness: [高 / 中 / 低]
plan.md 作成前に対処が必要な点: [あり / なし]
```

漏れや要確認事項があれば、`workspace/research.md` の更新を提案する。
