# ADR-0005: 恒久規範の面積指標を行数から文字数へ替え、常時ロード面に skill description を含める

ADR-0001 の決定（面積の代理指標を行数とする）を、実測を得たので改める。ADR-0001 の骨格（機構で担保する・二面を独立に ratchet する）は変えない。

## 文脈

ADR-0001 は「行数が粗い代理指標である（密度で誤魔化す余地が残る）ことは承知の上で受容した」と書いた。当時これは想定上の欠点だったが、2026-07-26 の規範圧縮作業で**実際に誤った行動を誘発した**。

- 常時ロードを 216→191 行に減らした同じコミットで、`rules` の基準を 173→155 に下げた。**rules は 1 行も減っていない**（述語の写しをポインタへ置換した行内編集のみ）。155 は変更前からの実測値であり、下げる行為は稼いでいない余裕の没収でしかなかった。
- 指標が「数字を下げること」を成果と見せ、削減していないのに削減したように振る舞う勾配を作った。行数指標では**改行を消すのが最も安い削減手段**であり、1 行 300 字を超える本リポジトリの規範文書ではこの歪みが特に大きい。

さらに、**毎セッション注入されるのにどの ratchet からも見えていない面**があった。`.claude/skills/*/SKILL.md` の `description` である（実測 995 字）。同じ日の作業でルート `CLAUDE.md` のスキル表からトリガー記述を削っており、その字を description 側へ移すだけで数字が下がる抜け道が現に開いていた。

## 決定

1. **指標を文字数（Unicode コードポイント・CR を除く）にする。** 定数は `LINE_BUDGET` → `AREA_BUDGET`（常時ロード 15685 字 / rules 8318 字＝切り替え時点の実測）。
2. **常時ロード面に skill の `description` を含める。** 1 行スカラーでない `description` は数えられないので finding に倒す（沈黙経路の閉塞）。
3. **skills 本文・モジュール `CLAUDE.md`・`docs/`・ADR は対象外のままとする**（下記）。

## 検討した代替案と却下理由

- **トークン数で測る**: 却下。文脈コストの代理として最も正確だが、トークナイザ依存を持ち込む（オフライン CI で壊れる・モデル世代で値が変わる）。文字数は勾配の向きが正しければ十分で、`governance:check` を依存ゼロに保つ価値の方が大きい。
- **行数のまま、密度の規約（1 行あたりの節の数など）を規範として足す**: 却下。#593 の階梯に反する（機構で吸収できるものを規範に戻す方向）。しかも密度規約は機械判定が難しく、規範を増やして面積を増やす自己矛盾になる。
- **skills 本文・モジュール `CLAUDE.md` も ratchet に含める**: 却下。**これらは「その作業に入った者だけが読む面」であり、常時ロードからそこへ退去させることは #593 と `/retrospective`「Step 3」が推奨する経路そのもの**である。課税すれば、登ってほしい階梯を登る側が罰せられる。加えてモジュール `CLAUDE.md` は通常の機能開発で正当に増えるため、ゲートが無関係な PR で赤くなり、赤の信用が落ちる。
  - **受容する残余**: ゆえに「ルート `CLAUDE.md` → `src-tauri/CLAUDE.md` へ字を移す」面替えは ratchet に映らない。これは抜け道であると同時に望ましい移動でもあり、**両者を機械で区別できない**（配置が妥当かは意味の判断であり `/retrospective`「Step 3」が担う）。
- **`description` を対象外のままにする**: 却下。毎セッション注入される＝定義上の常時ロードであり、除外の理由が「測っていなかったから」以上に無い。

## 帰結

- 基準の引き上げは `AREA_BUDGET` を理由コメント付きで更新する（摩擦の形は ADR-0001 のまま）。**引き上げの記録は行数時代の推移と地続きで定数コメントに残す。**
- 文字数指標では、体裁の変更（折り返し・表の整形）でも数字が数十字動く。ADR-0001 が受容した「粗さ」の質が変わっただけで、精密なメーターではないことは変わらない。
- `docs/superpowers/specs/2026-07-19-doc-minimization-design.md` §2 の「行数ゲート」という記述は歴史側の資料であり、追随させない（#589 で非規範化済み）。
