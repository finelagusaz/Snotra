# ADR-adr-frozen-history: ADR は凍結された歴史——検査は実在の辺だけを守り、精度の辺を畳む

日付: 2026-08-03 ／ 状態: 承認

## 決定

**「歴史は、消えることに対してだけ守り、変わることに対しては守らない。」**

`docs/adr/` を G-references・G-spec-sections・G-heading-refs・G-near-heading-refs の**走査元**から外す。ADR 本文は決定日時点の世界の記述として凍結し、そこから外への参照（パス・見出し・SPEC 節）は生きた層の改名・移動に追随させない——commit message の中のパスを誰も直さないのと同じ扱いである。

残すのは**実在の辺**だけである:

- 生きた層 → ADR の短縮引用（G-adr-citations。規範の根拠が消えたら赤）
- ADR → ADR の短縮引用（同上。`adrCitationDocs` が `docs/adr/` を明示的に足し戻す——`governanceDocs` の除外に連動して沈黙で消えないよう、母集団カナリアのテストが膜を張る）
- ADR ファイル名規約（G-adr-file-names）
- 生きた層 → ADR **見出し**の正準参照(照合される。走査元の除外は参照先のアンカー解決を絞らない——解決は snapshot 全体に対して行われる。この独立性はテストで固定した)

これは #893 が G-stale-identifiers に導入した非対称（歴史は語彙を供給しない・検査もされない）を全検査へ揃える変更であり、同時に `ADR-stale-identifier-detector-scope` が書いた「`governanceDocs` は `docs/adr/` を含む。この非対称は正しい——ADR が指すパスは今日も在るべき」という正当化を**覆す**。同 ADR は凍結ゆえ編集しない——それ自体が本契約の初適用である。

## 経緯（実測）

2026-08-03 のガバナンス機構実績調査（#894 の背景調査）で、G-heading-refs の稼働後捕捉の大半が ADR 内の腐りだったと判明した。実装前の複製変異による実測:

- 見出し照合 203 件中 **86 件（42%）が ADR 内**——機構の仕事の 4 割が「歴史の研磨」だった
- ADR 内の短縮引用 76 件 / findings 0——実在の辺は保守費ゼロで残せる
- ADR 内の G-references / G-spec-sections findings 0——腐り在庫を隠すための除外ではない
- 生きた層から ADR 見出しへの正準参照は 2 件（`RETROSPECTIVE.md`・`docs/build-commands.md`）あり、いずれも変更後も照合され続けることを実測した（初稿は「0 件」と誤認しており、独立レビューが訂正した——事実確認をせず凍結される文書へ数字を刻みかけた点で、この計画自身が本 ADR の背景にある事故類型を再演しかけた）

## 却下した代替案

1. **現状維持（ADR も精度照合する）**: 却下。生きた層で見出しを改名・移動するたびに過去の全 ADR を直す義務が生じ、照合の 42% を歴史の研磨に払い続ける。実績調査は、この保守が読者を誤りから守った記録を 1 件も見つけられなかった（捕捉はすべて「歴史の中の指し先がずれた」であり、実害の記録が無い）
2. **ADR 全削除（歴史は git log だけに置く)**: 却下。生きた規範・スキル・コードコメントから `ADR-<slug>` への根拠引用が 60 件超あり、宙に浮く。否定の知識（なぜ B を却下したか）は現役の判断材料である
3. **被引用 ADR だけ検査対象に残す**: 却下。引用の有無で本文の契約（腐りうる/腐らない）が変わり、読者がどちらのモードの文書を読んでいるか判定できない。契約はディレクトリ単位で一様であるべき
4. **G-adr-citations も畳む（実在の辺も手放す）**: 却下。ADR の削除を機械的に安全へする唯一の装置である（被参照ゼロの検算・2026-08-03 の 6 本削除で実証）。実在検査は削除時にしか鳴らず、保守税がほぼゼロ

## 受容する残余

- ADR 本文から生きた層への参照は今後黙って腐る（設計どおり）。読者への契約は本 ADR と `.claude/rules/governance-docs.md` の 1 行が担う
- ADR を削除するときは、生きた層に残る引用を先に散文化してから消す（G-adr-citations が赤で強制するため、手順を忘れても沈黙はしない）
