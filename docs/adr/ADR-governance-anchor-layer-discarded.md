# ADR-governance-anchor-layer-discarded: 錨の層を捨てたとき、2 サイクル待つ案と manifest の列へ置き換える案を却下した

2026-08-20、`ADR-governance-meta-demotion` で格下げしたばかりの**錨の層を、観測期間を待たずに撤去した**。撤去したのは `domains.mjs`（17 ドメイン × 39 錨）・`G-domain-anchors`・各検査の `domains` 宣言 21 本・`registry.mjs` の宣言契約・`manifest` の `domains` 列・`instrument.mjs` の `duplicateDomains`・evidence の未移行ラチェット。**この ADR が残すのは、そのとき却下した 2 案である**——撤去後の姿はコードの不在が持つ。

## 撤去の根拠

- **メタ層は「作りきるか捨てるか」の二択である（利用者の裁定・2026-08-20）。** 具体を触ると抽象に響き、抽象を触ると具体に響き、レビューの過程で必ずメタ層を通過するため、修正が連続する。半端に面だけ残すと「通過はするが、どこが効いているかは読まないと分からない」状態になる。
- **連続する修正は体感ではなく実測である。** 検査ファイル分割（`4f5f4d3f`）以降の (検査 × 改修コミット) 21 件のうち **17 件が母集団・メタ層の変更由来**で、1 つの変更（`48bf21eb`）が 11 本の検査を巻き込んだ。#1143 では機構が 3 日前に自分で開けた穴を自分で塞いだ（未被覆 51 本のうち 45 本は #1093 が生んだもの）。
- **格下げは強制力を外しただけで、面は残っていた。** `governance:check` が赤くならなくなっても、`.claude/rules/` を触る者は錨を読む。**利用者が名指しした痛み（母集団の特定という認知作業）は、面が在る限り消えない。**
- **`SPEC.md`・コード・テストが主役で、ガバナンス検査は引き立て役である。** 錨の層はこの比重を逆転させていた。

## 錨の層が何の代償だったか

17 ドメインのうち **16 が `snapshot.files` 由来**（ファイルシステムの glob 走査）で、外部の正本を持つのは `workspaceMembers`（`Cargo.toml`）だけだった。`docs/development-principles.md`「列挙の完全性」が挙げる 4 つの正本——コンパイラ / ソーステキスト / ファイルシステム / 外部設定——のうち、**誰も編集していないのに黙って縮むのはファイルシステムだけである**。

**錨は「ガバナンスの代償」ではなく「走査由来の母集団を選んだことの代償」だった。**

## 却下 1: 2 サイクル待ち、発火 0 件を確認してから撤去する

`ADR-governance-meta-demotion` が置いた規則がこれである。却下の理由は 2 つ。

- **観測しても分からない。** 格下げ中の発火が 0 件でも、それは「欠陥が無かった」とも「検知できていない」とも読める——**壊れ方が沈黙である層では、この 2 つを区別する観測が原理的に作れない**。同 ADR 自身が「止めたことによる害も沈黙する」と残余に書いている。
- **待つ間、面は残り続ける。** 上の「格下げは強制力を外しただけ」がそのまま費用として発生する。

**得られたはずのものは失う**——撤去時に「何が見えなくなったか」を発火実績で言えなくなる。代わりに下の「受容する残余」で名指しする。

## 却下 2: `manifest` の列を 13 足して置き換える

`manifest` は母集団の逐語の一覧をリポジトリへ持ち、CI が base と head の差分を取り、差分は PR 本文で逐語宣言を要求する。**縮めば `-<file>` が出るので沈黙しない**し、錨と違って錨の錨を必要としない。今日 4 列（`checks` / `docs` / `rules` / `skills`）が覆っており、残る母集団を列にすれば錨の存在理由は原理的に消える。

却下したのは **機構を別の機構へ替えるだけで、比重の問題を解いていない**ためである。加えて **`#1143` は manifest では捕まらない**——あのとき壊れたのは母集団ではなく `.claude/rules/` の `paths` の被覆で、列にしても差分は `+51`（増加）として出るだけだった。**錨が捕まえる欠陥と manifest が捕まえる欠陥は重なるが一致しない**ので、「13 列にすれば錨が不要」は未実証の主張である。

## 受容する残余

- **母集団が黙って縮んでも、どの層も赤くしない。** 走査の述語が狭まる・glob が対象を落とす形は、21 本が空虚に緑を返したまま通る。**気づく契機は人の目だけである**（#1143 はそうやって見つかった）。`runAll` の 0 件検知は残るが、それが見るのは**空になった**ときだけで、**縮んだ**ときは見ない。
- **ドメインを 1 つ丸ごと消しても誰も見ない**——という残余は、ドメインごと消えたので存在しなくなった。
- **格下げの機構は 2 件のために残っている**（面積計器の入力ガードと evidence の供給断検知）。`SNOTRA_GOV_META_AUDIT` と `/health-check`「Check 11」はその 2 件のために生きている。**錨の層はもうその観測の対象ではない。**
- **同じ提案が再び出たときの起点**: 走査由来の母集団を宣言由来へ変えれば、この層は要らなくなる。それは錨を足す話ではなく、母集団の正本を替える話である。
