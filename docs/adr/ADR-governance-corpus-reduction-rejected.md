# ADR-governance-corpus-reduction-rejected: ガバナンスの費用を下げるとき、守る対象の縮小と検査の選別を却下した

2026-08-20、#1148（ガバナンス機構の縮小・見直し）で検討した 3 方向のうち、**方向 1（メタ層の格下げ・`ADR-governance-meta-demotion`）だけを実施し、方向 2 と方向 3 を却下した**。**この ADR が残すのは、そのとき却下した 2 案と、却下の根拠になった前提の棚卸しである**——同じ提案が再び出たときに、測り直しから始めずに済むように。

## 前提の棚卸し（この 3 方向が立っていた土台）

**根になっていた誤り: 「費用」を一つの通貨として扱っていた。** 実際には 3 つある。

1. **リポジトリの維持費**（コミット数・行数）
2. **セッションの認知作業**（母集団の特定と調整。**利用者が名指しした痛みはこれ**）
3. **ゲートの摩擦**（赤で作業が止まること）

方向 3 は (1) を叩く案で、痛みは (2) に在り、方向 1 は (3) と、(2) の発生源を止めた。**見積もりを 3 度続けて過大に出した原因はすべてここにある**——字数（1 の代理）を先に見て、依存を後で測っていた。

| 前提 | 判定 | 根拠 |
|---|---|---|
| 既存の検査が維持費を発生させている | **ほぼ偽** | 検査ファイル分割（`4f5f4d3f`・2026-08-16）以降の (検査 × 改修コミット) 21 件のうち、**検査自身の欠陥で直ったものは 0 件**。原因の内訳は母集団・メタ層の変更 17 件、製品/スキル追随 4 件 |
| 守る対象（分母）を減らせば費用が下がる | **未測定。かつ上の行が反証の方向を指す** | 費用の 17/21 は母集団の**定義を触ったこと**が原因であり、分母の大きさではない。文書を減らしても定義は減らない |
| 実装が速く、機構が追い付いていない | **偽** | 機構の全生涯 83 コミットのうち **65（78%）が `.rs` を 1 行も触っていない**。二つの流れは交わっていない。#1143 が見つけた未被覆 51 本のうち 45 本は #1093（機構自身の分割）が 3 日前に生んだもので、**機構は自分が開けた穴を塞いでいた** |
| 機構の費用は製品開発と同量 | **偽** | 全生涯（2026-07-01〜08-20）で全 438 コミット中、機構 83 / 製品 185。同量に見えたのは **#1148 の見直し作業で埋まった 8 日の窓**だけである（`ADR-governance-meta-demotion` の訂正） |
| 文書の整合を守ることに価値がある | **原理的に測れない** | 腐りの実害の先例（#977 の偽の全称・陳腐化した ADR の却下理由）は在るが、頻度は観測できない。**受容する** |

**測定不能として記録する**: 検査単位の改修回数は、`4f5f4d3f` より前は帰属が取れない（それ以前は単一ファイルだった）。ゆえに上表 1 行目の射程は 2026-08-16 以降である。

## 却下 1: 方向 2 — 文書整合の 13 本を一本ずつ triage して減らす

**回収する費用が存在しない。** 上表 1 行目のとおり、検査は自身の欠陥ではほとんど直されていない。triage は「この検査は何を守っているか」を 13 回裁定する作業で、**その費用は確実に発生し、削減される費用は測ると 0 に近い**。

加えて、13 本が守っている対象（規範文書の参照・索引・命名）は**将来の全セッションを操舵する**面であり、価値は測れないが実害の先例は在る（上表 5 行目）。**測れない価値を、測ると 0 の費用と引き換えに削るのは割に合わない。**

## 却下 2: 方向 3 — 守る対象（分母）そのものを縮小する

測った分母は**構造的に健全だった**。

- ガバナンス対象の `.md` は 111 件 / 730,576 字。**逐語で 2 文書以上に現れる文は 22 件のみ**（40 字以上・フェンス外）
- そのうち行動対象は少ない: 対訳（README の 6 件）は正当、ADR 同士は凍結、**生↔生は 3 件**
- ADR は 64 本中 **57 本が生きた層から引かれている**（引かれていないのは 7 本）
- 設計文書 81 件は既に `docs/superpowers/` に在って課税の外（正本置き場は `docs/design/`）

実行可能なレバーは 2 本しか残らず、合計で **1,191 字と写し 3 件**だった。**`.claude/rules/governance-docs.md` の「書く約束」と既存の機構は、仕事をしていた**——相互参照 289 本は写しの治療結果であり、削るのは反目標である。

**この却下は「レバーを実行してはならない」ではない。** 1,191 字（`docs/check-skill-skeleton-design.md` の「検討した代替案と却下理由（ADR へ回収する）」節——見出し自身が回収を宣言しながら元が残っている）と生↔生の写し 3 件（モード優先順位・初期言語判定・check 系スキル 3 本の共通文）は、**触る用があったときに畳めばよい**。単独で企てる規模ではない、というのが却下の内容である。

## 受容する残余

- **逐語の写ししか測っていない。** 同じ事実を別の言い回しで書いた写し（#977 で 5 枚・#1056 で 6 枚目が PR 本文）は、この計測に原理的に映らない。**「写しは少ない」ではなく「逐語の写しは 22 件」までしか言えない**。安い探索の入り口は ADR の「帰結」節（導入時の写しの地図。#1139 で独立導出と全件一致）
- **測れない価値を受容する判断である。** 文書整合の 13 本を残すのは、価値を測れたからではなく、**削る費用の回収が測ると 0 だから**である。将来この均衡が変わるとすれば、検査自身の欠陥修正が積み上がったときである——数え直す起点は上表 1 行目と同じコマンドでよい
