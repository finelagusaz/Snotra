# ADR-governance-meta-demotion: メタ層をゲートから計器へ格下げしたとき、撤去する案と据え置く案を却下した

2026-08-20、ガバナンス機構のうち**主題が機構自身である層**（以下メタ層）を `governance:check` の exit code から外した。**この ADR が残すのは、そのとき却下した 2 案と、戻す条件である**——格下げ後の姿は `scripts/governance-check.mjs` の `META_CHECK_IDS` と `metaAuditEnabled` が持つ。

## 格下げの根拠

- **稼働実績が 1 日しか無い。** 錨の層は `e9bdf932`（2026-08-19）で生まれ、この決定は翌 8-20 である。実運用での発火はゼロで、「効いている」を支える観測点が存在しない。
- **費用は測れている。** 直近 8 日 50 コミットのうち機構コードに触れたものが 19、製品コード（`*/src`）に触れたものが同じく 19。Phase 1〜3（`e9bdf932` / `b154ad57` / `2f2c0a37`）は 2,065 行の追加で、`.rs` は 0 行だった。
- **後追いは実装に対してではなく、機構自身に対して起きていた。** #1143 が「rules の `paths` が `scripts/governance/**` の 51 本を覆っていない」と見つけたその 51 本のうち **45 本は #1093（機構自身のディレクトリ分割）が 3 日前に生んだ**ものである（`git log --diff-filter=A` で実測）。積み残しの生産者と消費者が同一であり、「追い付く」状態が構造的に来ない。
- **止めることが唯一の実験である。** メタ層の壊れ方は沈黙なので、動かしている限り「効いているか」を外から測れない。片側だけ確からしいということはなく、**壊れても気づけない層は、効いていることも確かめられない**。

## 格下げの線 — 「メタかどうか」ではなく「止めたとき 21 本の合否が信用できなくなるか」

母集団が空になれば 21 本は空虚に緑を返す。それは**21 本自身の故障**であってメタ層の話ではない。ゆえに `runAll` の 0 件検知・`lib.mjs` の入力ガード・`registry.mjs` の走査と形式検証・`manifest` の `checks`/`docs`/`rules`/`skills` 列はゲートに残す。

格下げしたのは、倒れても 21 本の合否が動かないもの——`G-domain-anchors`、面積計器の入力ガード、evidence の供給断検知、`manifest` の `domains` 列、および `domains.test.mjs` の錨の総称反証テストである。

## 却下 1: いま撤去する（コードごと消す）

**消すと、廃止できる根拠が二度と取れない。** `ADR-retire-area-budget` は面積の判定を廃したとき計器を残し、そのおかげで「通算 4 観測点で欠陥検出ゼロ」という実績が積めた。消していればその 4 点は存在しない。**撤去は観測の後に来る**。

加えて、撤去は「効いていなかった」という主張を含むが、いまその主張を支える観測は 1 日分しか無い。**費用が測れていることは、価値がゼロであることの証拠ではない。**

## 却下 2: 据え置き、規範で「これ以上メタ層を足さない」とだけ約束する

`ADR-retire-norm-review` が測ったとおり、規範は機構の代わりにならない。加えて据え置きは**痛みを一切回収しない**——メタ層が赤で止める限り、#1143 型の後追い（機構が自分の開けた穴を塞ぐ作業）はそのまま発生し続ける。格下げの実体は「赤で止まらなくなること」であり、そこが回収点である。

## 却下 3: 実行ごと止める（コードを凍結して置く）

印字も出なくなるので読む対象は減るが、**「発火したはずだった回数」も同時に消える**。それは撤去と同じ情報損失を、撤去の利点（行数が減る）なしに引き受ける形になる。

## 戻す条件・撤去する条件

サイクル末の `/health-check` が `SNOTRA_GOV_META_AUDIT=1` を立てて `governance:check` と `npm test` を走らせ、**格下げ中のメタ層の発火件数を数える**。

- **発火した** → その項目**だけ**を `META_CHECK_IDS` から外してゲートへ戻す。全部ではない。
- **2 サイクル連続で 0 件** → その項目を撤去する。撤去時はこの ADR へ観測点を追記する。

**この判定を機構で自動化しない。** 自動化すれば、それ自身が「メタ層を守るメタ層」になり、いま止めようとしている再帰をもう一段伸ばす。

## 受容する残余

- **格下げ中の印字は検出チャネルではない**（「検出は exit code、出力は証拠」・#471）。読まれないまま流れる前提で置いており、読む責任は `/health-check` の手順にある。手順を踏み損ねればメタ層の発火は誰にも数えられない。
- **止めたことによる害も沈黙する。** メタ層の失効は緑が緑のまま推移する形で起きるので、「何も起きていないように見えること」は無事の証拠にならない。監査モードの実行だけがその窓である。
