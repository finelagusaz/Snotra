# ADR-hooks-doc-retired: フックの実装契約を文書から外し、テストとコードのコメントへ置く

## 文脈

#1334 で `docs/hooks.md`（約 17,000 字）の条項を、置き場所の順（テスト・型 → 安いテスト → 該当箇所のコメント → 文書 → 消す）で振り分けた。PreToolUse 節の大半は `.claude/hooks/pre-bash.mjs` の先頭コメントと各判定の doc の写しで、テストが守っていた。文書にしか無かったのは、判定単位を構文的位置で定義する具体則からの逸脱の理由・行継続・`.\` 相対形などの数件と、RA の扱い（位置づけ・壊れ方・リポジトリ外の残余）だけだった。

## 決定

`docs/hooks.md` を撤去した。PreToolUse の契約の正本は `pre-bash.mjs`（先頭コメントと各判定の doc）とそのテスト、RA の扱いの正本は `lsp-config.mjs` の先頭 doc である。テストが守っていなかった規則（git 判定のコマンド位置・要約ゲートの `workspace/` 接頭辞・git 上限の和と hook の timeout・拒否文言の代替手段）にはテストを足した。

## 検討した代替案と却下理由

- **hooks.md を小さく残す（RA の 3 項目と、外から参照されている見出しだけ）**: 却下。`AGENTS.md`「ドキュメント参照」と `docs/development-principles.md`「規範の書式は文書の役割から選ぶ」は、この文書の書式を「射程の宣言と逸脱の明記の対」と定めていたが、逸脱の明記をコードへ移すと文書に残るのは対の片方も持たない 3 項目になり、その書式の説明が中身を失う。残る 3 項目は RA の設定を触る人にだけ要る内容で、その人が開くのは `lsp-config.mjs` である。
- **テストを足さず、規則をコメントへ残す**: 却下。敵対的調査で、規則を破る変異（コマンド位置のアンカーを緩める・接頭辞判定を緩める・上限を 40 秒にする・拒否文言から代替手段を消す）が全テスト緑のまま通ると分かった。どれも数行のテストで落とせるので、置き場所の順の「安くテストにできるならテストにする」に当たる。

## 帰結

- hooks.md を「正本」と書いた ADR（`ADR-claude-code-ra-lsp-plugin-delivery` ほか）は宛先を失うが、凍結された歴史として触らない。
- `docs/development-principles.md` の役割の表から「改修者向けの実装契約」の行が消えた。射程宣言の一般論は同節の書き換えテストの条項に残る。
