# ADR-norm-review-batched-runs: `/norm-review` の対照・本番を種ごとに起動しない

## 却下した案

### 種ごとに対照と本番を別エージェントへ渡し続ける

却下する。実測では4種が8ランになり、別の2回では合計14ランへ増えた。対照と本番の独立性は必要だが、同じ側の種同士まで別コンテキストにする費用に対応する検出力は記録されていない。全種を対照1体と本番1体へまとめ、両側の分離だけを残す。

### 対照を廃止して本番だけを実行する

却下する。4種の初回実測では2種を本番が捕まえ、残り2種は対照も捕まえたことで条項不要と判定できた。対照を消すと、規範を増やさないための証拠を失う。

### 同じエージェントで対照から本番へ続ける

却下する。対照で導いた答えが本番へ残れば、変更後の規範が効いたのか会話履歴が答えを運んだのか区別できない。エージェント数は2体へ下げるが、対照と本番は別コンテキストに保つ。

### 文言修正後に対照も取り直す

却下する。同じ種から変更した条項を除いた対照は、条項の文言だけを直しても入力が変わらない。種・変更前の基準・期待結果が変わった場合だけ取り直し、それ以外は本番だけを再実行する。

### 通常の種蒔きと pressure scenario を自動で併用する

却下する。直近14ランでは規律型への分岐が0回で、通常の種は「正しく実行できるか」しか測っていなかった。異なる失敗様態を同じ起動へ混ぜず、規律型は `--pressure` を明示した別の2体で測る。
