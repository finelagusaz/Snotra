# メタ層の格下げ — 独立導出と敵対レビューの原文（2026-08-20）

`docs/adr/ADR-governance-meta-demotion.md` が結論を持つ。**ここに置くのは、その結論を出した 2 つの導出の原文である**——2 サイクル後の撤去判定は「どの項目が争点で、どちらの側がどんな根拠を出したか」を要る。要約に落とすと、そのとき必要になる根拠が消える。

- **Fable（独立導出）** — 「機構を守る機構は、それ自身を機構で守らない」の下で撤去できるものの列挙。呼び出し側の結論は渡していない。走査範囲は `scripts/` / `.claude/` / `docs/adr/` / `docs/development-principles.md`。
- **Codex 0.147.0（敵対レビュー）** — 「メタ層の欠陥は遅れて気づいても害がない」の反証を求めた。

**採否のうち、原文と結論が割れた点**（裁定は ADR ではなくここに残す）:

1. **Codex の総括は採らなかった。** 「命題は false」と結論しているが、挙げた 5 件のうち **4 件に Codex 自身が「後から気づいて足りた」と裁定を付けている**。`手遅れ` を付けた 1 件（#1143）も、同じ報告内で「記録はこの間に偽の規範文書又は誤判定 PR がマージされたとは述べない」と断っており、根拠は滞留時間であって着地した被害ではない。**採ったのは所見であって総括ではない**（ルート `CLAUDE.md`「サブエージェント委譲と worktree」）。一方 Codex が本当に壊したのは別の命題——「新設時に一度フォールトインジェクションすれば以後は信用できる」——で、そちらは #1143 が直接の反例である（`.claude/rules/safety-nets.md` へ反映済み）。
2. **Fable の項目 4（`manifest` の `domains` 列は撤去可）は、理由を採らず結論だけ採った。** Fable の理由は「ドメイン削除は可視の編集だから」だが、判定基準は可視かどうかではなく沈黙するかどうかである。採った理由は別で、**錨の層をゲートから外した以上その帳簿だけをゲートに残すのは筋が通らない**、という一貫性である。
3. **Fable の項目 3（domains 宣言のラチェット）は部分採用にとどめた。** 格下げしたのは evidence 行の未移行残数だけで、`registry.mjs` の宣言契約（空配列・未知名の throw）はゲートに残してある——費用が「新しい検査を足すたび」にしか発生せず、いま検査を足すことを止めている以上、放っておけば費用は自然にゼロへ向かう。
