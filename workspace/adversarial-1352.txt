== 壊せなかった項目（反証を試みて残った）==

[S1] 命題 1: spawnSync(shell:true, timeout) の timeout は直下の cmd だけを止め、npx node → cmd → vitest → worker の 4 つが、駆動スクリプトの終了後も残る。drive.mjs shell を実行し、終了後に ParentProcessId で確認: 4 つ全部生存、worker の CPU 累計は増え続けた（drive3 shell: 11.7 → 15.1 → 20.0 秒、約 1 コア）。
