== 争点 ==
1. [壊せなかった] インライン IsWindowVisible
   - lib.rs:263-280 の分岐、`window_getter!` → `getter!` (send_user_message → recv)、lib.rs:3285 `WindowMessage::IsVisible(tx) => tx.send(window.is_visible())` を実測。
   - tauri::Window::is_visible (tauri-2.12.5/src/window/mod.rs:1674) は dispatcher.is_visible に直結。
   - 窓が windows map に無い、または inner が None のときは tx が drop され、recv は Err を返す。ハングはしない。`unwrap_or(false)` で成立。
   - 偽にする手順: イベントループ上で `is_visible()` を呼び、`current_thread().id() != main_thread_id` になる経路を作る。on_event_loop は run_on_main_thread で Task を post するので、Task はメインスレッドで実行される。
   - 補足: hotkey 経由は別スレッドから Message::Task を post し、イベントループの UserEvent 処理で走る。その中の getter もインライン。
2. [壊せなかった] hide()/show() が戻った時点で IsWindowVisible が確定する
   - tao window.rs:128 の set_visible → thread_executor.execute_in_thread。event_loop.rs:518 で in_event_loop_thread() ならインライン実行。
   - window_state.rs の set_window_flags は同期の apply_diff を呼ぶ。`!new.contains(VISIBLE)` なら無条件に ShowWindow(SW_HIDE)、`new.contains(VISIBLE)` なら末尾で無条件に SW_SHOW。diff が空でも走るので、tao のフラグが OS 状態とずれていても効く。
   - 偽にする手順: window.hide() 直後に IsWindowVisible が true を返す実測。SW_HIDE は同期で、戻り時点で WS_VISIBLE は落ちている。
   - 再入の検討: ShowWindow が同期で WndProc を呼んでも、tao の runner.send_event は should_buffer() で非 RedrawRequested イベントをバッファする。show()/hide() の最中にフレームや hotkey Task が割り込むことは無い。
   - ⚠️ 弱点 (確度中): RedrawRequested だけはバッファされず call_event_handler へ直行する (runner.rs:208-214)。show_egui_main の window.show() の最中に、main 自身の RedrawRequested が同期で届くかは未確認。
     - 届くなら、キャッシュなら false (set は show 後)・実状態なら true、という差が出る。ただし既存コードでも再入できるなら別の問題が出ているはず。
     - 確かめるには、show 中の WM_PAINT 再入を trace で観測する (本調査では未実施)。
3. [壊せなかった] main の可視性を変える経路は 2 か所だけ
   - src-tauri/src と snotra-egui-runtime/src を `.show()/.hide()/set_visible/ShowWindow/SW_HIDE/SW_MINIMIZE/set_minimized/CloseRequested/on_window_event` で探した。
   - main に効くのは show_egui_main の window.show() と hide_egui_main の window.hide() のみ。
   - results_window.rs:340-370 の生 ShowWindow は results 用。main のハンドルは `ResultsWindow` に入らない。
   - single-instance のコールバックは show_egui_main を呼ぶ。トレイは SetTrayVisible だけで、main を触らない。
   - CloseRequested は egui の ViewportEvent::Close に変換されるだけで、直接の hide ではない。
   - tao 内部: 最小化 (window_state.rs の SW_MINIMIZE) では WS_VISIBLE が残るので、IsWindowVisible は true のまま。キャッシュと同じ。Win+D、cloak、仮想デスクトップも IsWindowVisible は変わらない。
   - tauri.conf.json の windows は [] で、main は mod.rs:354 で `.visible(false)` で生成。
   - 偽にする手順: 上記 grep 以外の手段 (SetWindowPos の SWP_HIDEWINDOW、WM_SYSCOMMAND、DefWindowProc による X ボタン後の自動 hide) で main が不可視になる経路を見つける。見つからなかった。
   - 限界: 外部プロセスが ShowWindow(main, SW_HIDE) すれば、キャッシュと実状態は食い違う。そのとき実状態の読みが正しい (これがこの変更の主張)。
