## 意図的分離 5 件の再検証（根拠そのものを攻めた結果）

DRY 違反としては挙げない。**根拠が成立するかを独立に確かめた結果、5 件とも成立している。**

1. **`results_area_collapsed` と `plain_results_hidden` を別述語のまま** — 成立。
   `search_state.rs` の `plain_results_hidden` は `(view_kind, instant_rows, indexing)` の 3 引数で
   Results ビュー限定の carve-out を持つ（`research.md` P7）。④は `SPEC.md:189`「この高さは `results` に描く
   **すべてのビュー**へ一様に適用される」ゆえ carve-out を持てない。統合すれば射程が壊れる。
2. **`FrameIndexing` と `FrameVisibleRows` を別型** — 成立。機構が違う（`AtomicBool` の live-read と
   config の live-read）ことは `view.rs:931-932` が書いており、隣接引数の取り違えを型で塞ぐ目的は
   `on_enter(shift_held: bool, indexing, visible_rows, ctx)` という実際の並びが裏づける。
3. **`activate_or_execute` と `shift_activate` に同形のガードが 2 つ** — 成立。
   `shift_activate` の `tools >= 2` 枝（`:649-661`）は `activate_or_execute` を通らず
   `SearchState::enter_tool` を直接呼ぶことをコードで確認した。1 か所では覆えない。
4. **`indexing_is_read_exactly_once_per_frame` と `visible_rows_is_read_exactly_once_per_frame` を別テスト** — 成立。
   前者を ADR が名前で参照していることを grep で確認（`ADR-activation-gate-placement.md:48`）。
5. **`present_results` は `desired_height > 0.0` のまま** — 成立。述語へ置き換えると、
   `layout.rs:416-417` の安全性が `Metrics::row_height` の床 24.0 の存在に依存する。
   ただし**この床への依存は `results_area_collapsed` の doc 側に既に在る**（W1）——
   「置き換えなかったから床に依存しない」のは `present_results` だけで、述語の正当性は床に依存している。
   分離の判断自体は正しいが、**依存が消えたわけではない**ことは押さえておくとよい。
