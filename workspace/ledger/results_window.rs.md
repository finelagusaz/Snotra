## Phase 1 で得た規則の追補（plan.md「分類規則」へ反映）

- 「旧 〜」は、同じ処理の中の前の値（旧 metrics・旧 state・旧色のうちフレーム間の前の値）なら残す。消えた型・関数（旧 `SearchWindowView::new`）を指すなら消す
- `決定 N`・`案 N`・`spec 決定 N` は `git log -S '<語句>' -- <file>` の最古のコミットの PR 番号へ置き換える
- 消えたシンボル名（`must_retract_results` 等）は、ADR が持つなら本文から落としてよい
- 経緯の段落が、今は偽の現在形の主張を含むことがある（B16）。その場合は消す（書き直して残す必要があるかは、同じ不変条件が別の doc に既にあるかで決める）
- 書き直しで名指しを足すなら、名指した関数が実際にその主張どおりであることを grep で確かめ、根拠欄に書く（B1）
