# 規則を全部守る読者 — 1巡目

1. **巡ごとの別パス規定が読者クラス間の衝突を禁じていない** — 「渡すパスは**巡ごとに別**にし……パスを再利用すれば前巡が数えられず」という文言は、区別の単位を「巡」としか述べておらず「読者クラスごと」とは書いていない。忠実に読めば、1巡目の中で「手を抜く読者」と「規則を守る読者」に同一パスを渡すことは禁止されていない。しかし両者が同一ファイルへ `Write` すれば後書きが先書きを上書きし、片方のクラスの指摘が消える——「N・Mは読者が書いたファイルの番号を数え直して立てる」という前提が成立しなくなる。関係する合格条件: 2, 5。

2. **不着ラウンドを表現するテンプレート枠が無い** — 出力形式は「1巡目: 手を抜く読者N件・規則を守る読者M件 → N+M = 成立K + 降格L」という数式一行に固定されている。一方で「起動して不着だったものは『省略』ではなく不成立として書く」とも定めるが、不着＝ファイルが存在しない場合、N（またはM）を「読者が書いたファイルの番号を数え直して」立てる操作自体が不可能になる。忠実な実行者は、数式行を偽の0件で埋めて厳守を装う（合格条件3の懸念に抵触）か、フォーマットを破って散文で書く（「出力の形式（厳守）」に抵触）かの二択に詰む。関係する合格条件: 2, 3。

3. **「1文まで」の分量予算と「原理で書け」という要求が両立しない場合がある** — Step1-4は「塞ぎ1件あたりの分量予算——1文まで」と定め、Step3は「保護対象を列挙する形で塞ぐと、逃げ道は列挙の隣へ移る。列挙ではなく原理で書けないかを先に問う」と要求する。単純な事例を除き、限定を持たない一般原理を1文で漏れなく記述することは難しく、無理に1文へ圧縮すると結局「対象を名指しする列挙」に近い形へ退行しがちである。どちらの規則を優先すべきかの順位が文言に無いため、忠実な読者は予算超過と禁止された列挙化のどちらを犯すか選べない。

4. **「機構への言及」が定義されておらず判定不能** — 「機構への言及も検出面の列挙として働き、読者を『何が正しいか』ではなく『何が検出されるか』の推論へ移す」とあるが、何が「機構への言及」に該当するかの基準・例が文言中に無い。悪意なく原理ベースの塞ぎ文を書こうとしている忠実な読者でも、自分の草稿が禁じられた「検出面の列挙」に当たるかどうかを機械的に判定する方法が無く、遵守しているつもりでも違反しているかもしれない状態から抜け出せない。関係する合格条件: 6。

5. **合格条件の事前確定（クローズドリスト）と「成立した指摘だけを塞ぐ」の無条件性が衝突する** — Step1は「決めなければ無限反復にも恣意的停止にもなる」として合格条件（通してはならないシナリオの列挙）を**着手前に**確定させるよう求め、Step2以降にこれを改訂する手続きは書かれていない。他方Step3は「成立した指摘だけを塞ぐ」とだけ言い、成立の判定基準を合格条件との一致に限定していない。2巡目の読者が、1巡目には想定していなかった新種の抜け道を発見し根拠の引用も確認できた（＝成立）場合、忠実な読者は「着手前に確定した合格条件の外だから対象外とすべきか」「成立した以上は塞ぐべきか」のどちらに従うべきか文言から決定できない。

6. **散文回答が「裁定」への回帰を招くと文言自身が認めている** — 「散文で返れば件数が裁定に戻る」という一文は、読者が指示（1件1番号の箇条書き）に従わなかった場合、N・Mの確定が客観的な番号の数え直しから主観的な「裁定」（＝会話や記憶による判断）へ後退することを自ら認めている。これは合格条件2が禁じようとしている経路そのものであり、かつ非準拠の読者出力に対する再実行・差し戻しなどの是正手続きが文言に存在しない。忠実な実行者が散文回答を受け取った場合、機械的な数え直しは原理的に不可能であり、それでも数式行は書かねばならないという矛盾に直面する。関係する合格条件: 2。
