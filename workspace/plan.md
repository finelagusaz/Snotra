調査の正本は `workspace/research.md`。本計画はその F5' の全件表と「振り分けの判定基準」に乗る。

## 目的

#1023（`ae3335df`）が撤去した語彙のうち、**読者が「今このリポジトリに在るもの」として探しに行く
形で残っているもの**を、探しに行かない形へ直す。**探しに行かない形で残っているものは直さず、
受容する残余として明記する。**

## 受け入れ条件

1. `PERFORMANCE.md` の 3 箇所（D・B・E）が、撤去済みであることを読者にその場で伝える形になっている
2. 直さないと決めた箇所（A ほか 8 群）について、**なぜ直さないか**が PR 本文に受容する残余として書かれている
3. `npm run governance:check` が緑（変更前も緑なので**退行が無いことの確認**であって、成果の検知ではない）
4. F5' の全件表が、**手選びを挟まない機械抽出**から導かれている（既に満たしている・再実行で検算する）
