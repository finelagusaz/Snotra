# 計画 — issue #1498 #1300 の試行を結論に持ち込み、スキルの足場を外す

## 目的と受け入れ条件

目的: #1300 の試行（高リスク計画の既定を `/plan-review` Step 2b に寄せる）に結論を出し、恒久の手順に残っている試行の足場を外す。

受け入れ条件（issue #1498 から）:

- A1 #1300 に結論が書かれ、閉じている
- A2 `git grep '#1300' .claude/skills` の結果が、結論に合った状態である（試行の足場が残っていない）
- A3 `npm run governance:check` が通る

## 設計の決定

- D1（Q1・結論）いまの選び方を、試行ではなく恒久の規則として残す。高リスクは既定で Step 2b、issue に書かれていない人間の裁定が計画の前提にあれば Step 2、どちらか一方だけを回す。根拠は 2026-11-15 の 2 つの集計（所見の数でも流出の数でも方式の優劣は決まらず、データが支えるのは「どちらか一方を回せば足りる」まで）と、未確定「Step 2 が 0 なら畳む」が成立しないこと（Step 2 は少なくとも 12 回選ばれた）。既定を 2b のままにするのは、2b を既定にした理由（独立導出は計画の網羅性の漏れを別の枠組みで拾う）が試行で否定されていないからで、2b が優るからではない
- D2（Q2）記録はやめ、足場を外す。単位をそろえて記録を続けても、方式の選び方と計画の性質が交絡しているので、この試行の形では優劣を決められない
- D3（Q3）`/plan-review`「リスク判定」から「この既定は #1300 の試行である。記録欄は…にある。」を消す。選び方の理由（Step 2b は issue の WHAT だけを渡すので、人間の裁定を知らず逆の導出を返す）は残す
- D4（Q4）#1300 には、結論のコメントを書いてから、PR の本文で `#1498` と一緒に閉じる（マージのときの `--closes` は `1498,1300`）
