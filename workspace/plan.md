# 実装計画 — issue #1214: G-module-index の逆方向を節へ絞り、残る死角を宣言する（案 A＋宣言）

## 目的

`G-module-index` の逆方向の照合を **`text` 全体から「モジュール構成」節へ絞り**（案 A）、それでも閉じない死角を**宣言して止める**（案 C の宣言部分）。

**判断の経緯**: issue #1214 は案 A を「実測したが効かない」として却下していたが、その実測は #1210 が踏んだ 1 例（`snotra-core/autostart.rs`）だけだった。索引行を持つ全 86 本へ 1 本ずつ削る変異を当て直すと、案 A は現行より **12 件多く捕まえ、現行ツリーへの掃除の費用は 0 件**である。ユーザーは この再測を見た上で「案 A＋宣言」を選んだ（2026-09-02）。

## 受け入れ条件

1. 逆方向の照合が「モジュール構成」節の中だけを見る。
2. **現行ツリーで `governance:check` が緑のまま**（掃除の費用 0 件の実測どおり）。
3. **フォールトインジェクションで、強くなった側と残る死角の両方を実測する**（下の 4 形＋対照）。
4. 検査ヘッダ・ADR を読んだ者が、**残る死角**（同じ節の中の別の索引行・集約行が同名に触れていれば緑）を issue を読まずに知れる。
5. 死角に反する既存の規範記述が残っていない（`AGENTS.md` の「索引漏れは編集直後に reminder が鳴る」・`docs/hooks.md` の reminder 発火表）。
6. `npm run governance:check` と `npm test` が緑。
7. 追記した文言に**数え上げ・全称表現・代理条件が無い**（`AGENTS.md`「検証の作法」）。実測値は日付つきで ADR（凍結された歴史）側へ置く。

## 不変条件と異常系

- **母集団を変えない。** `moduleIndexSources` も `MODULE_INDEX_CRATES` も触らない。変えるのは**照合先のテキスト範囲だけ**である。
- **`sectionOf` の失敗経路を壊さない。** 節が見つからない / 終端見出しが失われた場合は既存どおり `sec.findings` を積んで **`continue`**（逆方向へ進まない）。ここを変えると、節が消えたときに全ファイルが赤く並ぶ。
- **本文が空の節は「節が無い」ではない**（既存の不変条件）。空の節では逆方向が**全件**を名指しする——案 A ではこれが本当に全件になるので、既存コメントの「『全件』ではない」を書き換える。
- **正本は 1 か所。** 残る死角の機序は検査ヘッダ、却下・採用の経緯と実測値は ADR。`AGENTS.md` / `docs/hooks.md` へは性質を書かず**指すだけ**にする。
- **数を書かない。** 「86 本」「+12 件」「48 本」はファイルや索引行が動けば偽になる。ADR の日付つき実測としてのみ書く。
- **全称へ倒さない。** 「索引行の消失は検知される」も「されない」も偽である。正しくは「同じ節の中に同名の言及が他に無ければ赤くなる」。
