  矛盾は無い**。⚠️ を付けているのは、PR 本文やレビューの往復で計画の A/B/C を
  そのまま引くと検査のメッセージと食い違う点だけ——`workspace/` はマージ後に
  読まれない面なので、PR 本文で計画の字を使わなければ実害は無い。

(c) `stripLead` を無効化する変異（検知件数が落ちることの実測）
--------------------------------------------------------------
  **HEAD のままでは測れない**——折れが 0 件なので `stripLead` を殺しても
  0 件のままで差が出ない。そこで**折れを実在させた木**を作った:
  親 13f8a2e7 から**折れだけを含む 22 ファイル**を復元した
  （`scripts/governance/**`・`scripts/governance-check.mjs`・`PERFORMANCE.md` は

   `AGENTS.md` の新しい正準形参照が**別の理由で**赤くなるため。
   これは「変異がその名指し側を別の理由で赤くする」汚染そのものである）。

  対照 1（`stripLead` 健全・折れ 30 件の木）:
      $ npm run governance:check → **exit 1** / **30 件**
